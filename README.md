# 🚀 Featured Projects

### 🩸 Red Pulse – Blood Donation Management System

A mobile-based blood donation management application designed to connect donors, manage emergency blood requests and improve blood inventory management.

**Key Features:**
- Emergency blood request management
- Priority-based donor matching
- Blood inventory and expiry notifications
- Donor eligibility and screening
- Blood donation camp management

**Technology Stack:** React Native, Expo, Node.js, PostgreSQL, Prisma, Firebase Cloud Messaging, Socket.io

### 🚗 QuickPark – Smart Parking Reservation System

A parking reservation solution that helps drivers discover and reserve available parking spaces.

**Technology Stack:** React, .NET, C#, PostgreSQL

### 🌾 Farmer2MarketLK – Agricultural Marketplace

A web-based agricultural marketplace that connects farmers with buyers and supports produce discovery and AI-powered request analysis.

**Technology Stack:** React, Node.js, Gemini AI, Cloudinary
